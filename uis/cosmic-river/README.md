# 每日一句 · 自定义指南

右上角竖排行楷的字句，全部由本目录的 `quotes.json` 决定，改这个文件就行。

```json
{
  "mode": "daily",
  "lines": [
    "仰观宇宙之大",
    "俯察品类之盛",
    "……"
  ]
}
```

- **lines**：想展示的话，一行一句。竖排陈列，建议每句 ≤ 12 字（太长会往左折列，
  折列也符合古书从右往左读，但单列最好看）。
- **mode**：
  - `"daily"` —— 每天零点（北京时间）自动按顺序换下一句，循环往复；
  - `"fixed"` —— 永远只显示第一句（比如就想常驻「仰观宇宙之大」时用）。

## 今天显示第几句？

首展日 2026-09-17 显示第 1 句，之后每天 +1，到列表末尾再回到第 1 句：

```
第几句 = (今天 − 2026-09-17 的天数) 除以 句数 的余数 + 1
```

## 改完怎么生效？

改完 `quotes.json` 提交推送（或在策展后台下载 `registry.js` 旁边手动提交本文件），
Pages 重建后全网生效，约 1 分钟。页面读取时不缓存，刷新即见新句。
