# shared/ · 馆藏库房

跨展品复用的**原子化资源**统一存放于此，例如某个 three.js 场景、一套通用按钮样式、公共字体等。

## 约定

- 每个原子一个子目录：`shared/three-planet/`、`shared/glass-card/` …
- 原子必须自包含，并附一个 README 说明用途、参数与来源
- 展品内引用方式（位于 `uis/<slug>/` 时）：`../../shared/<atom>/…`
- 原子升级保持向后兼容；破坏性变更请新开版本目录（如 `glass-card-v2/`），旧展品不受影响
