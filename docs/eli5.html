界面收藏馆
是怎么工作的？

一个大字版说明：网站原理 + 怎么添加新展品

壹全馆只有三样东西

🌐 一个网站
🏛️ 总台 = index.html（你看到的大页面）
📖
registry.js
登记册：馆里有哪些展品，它说了算
🚪
uis/
展品房：每套 UI 独占一间
📦
shared/
库房：大家共用的零件

没有框架、没有构建工具 —— 就是一堆纯 HTML / CSS / JS 文件，放在 GitHub 上，GitHub 替你向全世界展示（GitHub Pages）。

贰展品是怎么「挂」上去的

🖼️
相框里那幅「画」是活的

总台给每件展品开一扇小窗（叫 iframe）， 展品就在窗里真实运行，再整体缩小 —— 所以你看到的是迷你版真页面，不是截图。

🖼️
在总台
小窗缩在相框里
扮演一幅画
→
🔍
点「步入展厅」
同一扇窗放大到全屏
不重新加载，3D 星球接着转
→
🚪
按 Esc
窗户缩回相框
回到总台
🔗
每件展品有门牌号
网址结尾是 #/exhibit/名字 就直接进入那件展品；删掉它就回总台。分享、刷新、前进后退都好使。

叁为什么强调「隔离」

🚪
每套 UI 一间房，家具不出门
自己的样式、脚本、图片全放自己屋里（uis/我的展品/）。改 A 展品，永远不会弄坏 B 展品。
📦
公用的零件放库房
比如两个展品都想用同一个 3D 场景？把它放进 shared/，两家来借同一份，不复制两份。

肆添加新展品：只做三步

1
🏗️ 盖一间房
新建文件夹 uis/我的展品/，里面放一个 index.html，整套 UI 全部自带。
2
📖 在登记册上挂号
打开 registry.js，照着 №001 抄一条：起个名字、写好路径 uis/我的展品/、贴上展签文案。刷新页面即开展。
3
📮 寄给 GitHub
git push 推上去，GitHub 约 1 分钟后自动发布，全世界可见。
💡
两条捷径
· 别人的网页不想搬？不盖房，登记册里直接填它的网址（№001 你的个人网站就是这么展出的）。
· 有共用零件？先放 shared/，再在展品里引用。

总台是相册，展品是活的小世界，登记册说了算。
